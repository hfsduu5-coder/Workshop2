# Academic & Professional Education Workshop — Cyber Team

An interactive Arabic presentation titled **آفاق التعليم الأكاديمي والمهني** developed for Cyber Team.

## Overview

A browser-based workshop experience focused on academic and professional education. The project uses an RTL slide interface with animated transitions and a dark Cyber Team visual identity.

## Features

- Arabic RTL presentation
- Interactive slide navigation
- Responsive interface
- Progress indicator
- Animated cyber-themed presentation design
- Single-file deployment

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Run Locally

Clone or download the repository and open `index.html` in your browser. No package installation or build step is required.

## Purpose

Created as an educational presentation for workshops and student activities.
